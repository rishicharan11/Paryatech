The details that make a handover work.

Give suppliers and teammates the same clear picture of the trip, the request and the decisions still waiting.

In this story

  1. Give each request a clear purpose.
  2. Send a complete, readable brief.
  3. Keep assumptions visible.
  4. Make changes easy to trace.
  5. Close the loop with the traveller.

Give each request a clear purpose.

A supplier message should make it obvious what you need next. Are you asking for an initial quotation, checking a specific arrangement or requesting a change to something already discussed? State that purpose at the beginning. Include a consistent trip reference so the reply can be matched to the right enquiry without relying on a traveller’s name alone.

Keep a new request separate from a general conversation where possible. A clear subject or opening line helps the supplier distinguish an urgent clarification from background information. It also helps your own team find the answer when they take over the enquiry later.

Send a complete, readable brief.

Include the dates, group size, required room arrangement, relevant route and the service you want quoted. Explain any preferences that materially affect the request. If one part is flexible, label it as flexible; otherwise a supplier may spend time checking an option the traveller cannot use.

Write the details in a compact list rather than hiding them inside a long paragraph. Before sending, compare the request with the current traveller brief. A copied message from an older version of the trip can create unnecessary confusion even when every individual sentence looks reasonable.

Keep assumptions visible.

Ask the supplier to clarify what is included, what remains excluded and which details need confirmation. If the quotation depends on a particular room category, transfer arrangement or number of travellers, keep that condition alongside the figure. A price without its context is difficult to compare and easy to misinterpret.

Do not treat a quotation as a confirmed booking. Use distinct language for “requested,” “quoted,” “awaiting confirmation” and “confirmed.” Follow the supplier’s actual process and record the evidence of a confirmation when it arrives. The team should know what is agreed and what is still being checked.

Make changes easy to trace.

When dates or arrangements change, summarise the difference at the top of the message. For example: “The group is now six adults, with the same arrival date. Please recheck the room arrangement and transfer size.” Attach or reference the current version rather than asking the supplier to reconstruct several conversations.

Keep the previous information available for context, but mark which version is current. Note who requested the change and which response you are waiting for. If a colleague covers the enquiry during an absence, they should be able to continue without sending the same request twice.

Close the loop with the traveller.

A supplier reply is useful only when it reaches the next decision. Review it against the original request, clarify any missing detail and update the enquiry. If the response changes a proposal already shared with the traveller, explain the difference clearly before moving ahead.

For internal handovers, leave three short notes: what is currently agreed, what is outstanding and who owns the next action. Keep relevant supplier correspondence with the trip record. That simple habit gives the next teammate a practical starting point and reduces the amount of work carried in personal memory.

Make the request clear enough that the next person can act on it.
